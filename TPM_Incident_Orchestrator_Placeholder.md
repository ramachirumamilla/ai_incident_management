# TPM Incident Orchestrator Copilot (Placeholder)

## Purpose

A TPM-focused AI agent designed to support incident management before, during, and after production incidents.

This is a placeholder design intended for future implementation using MCP (Model Context Protocol) integrations.

---

## TPM Persona

The primary user is a Technical Program Manager (TPM).

The TPM is responsible for:

- Coordinating responders
- Driving incident cadence
- Managing stakeholder communication
- Tracking decisions and risks
- Protecting delivery commitments
- Ensuring post-incident follow-through

The TPM is not responsible for:

- Debugging code
- Analyzing logs
- Performing technical root cause analysis
- Executing production changes

---

## Agent Mission

Keep incidents organized while engineering teams focus on technical recovery.

The agent helps TPMs:

1. Coordinate people
2. Track ownership
3. Document decisions
4. Communicate business impact
5. Assess program risks
6. Drive accountability after resolution
